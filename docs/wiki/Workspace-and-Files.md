# 认识界面与文件

[返回目录](Home.md) · [English](Getting-Started.md)

## 界面的几个部分

- **上方功能区**：按“开始”“图层”“样式”“创建与工具”等入口组织功能。
- **中央预览**：拖动、缩放地图，查看当前城市和取景范围。
- **设置面板**：调整所选图层、线路或导出内容的具体参数。
- **状态与进度**：查看载入、生成和导出的进度。

普通地图、公共交通图和地铁示意图承担不同用途。切换到对应视图后，功能区和可用输出也会跟着变化。需要回到道路、建筑等城市图层时，选择“返回城市地图”。

## 三类文件

| 文件 | 保存的内容 | 什么时候使用 |
| --- | --- | --- |
| `.cmm`、`.cmm.gz` | 从游戏导出的城市数据 | 在查看器中重新浏览和出图 |
| `.mmap`、`.mmap.gz` | 早期格式的城市数据 | 打开过去保存的地图数据 |
| `.png`、`.html`、`.svg` | 已生成的地图图片或网页 | 分享、浏览、打印或排版 |
| RMG、RMP 项目 | 可继续编辑的线路图内容 | 后续调整线路与版面 |

SVG 来自地铁示意图的编辑工作区。各视图支持的输出见[选择范围与导出](Export.md)。

## 地图数据是一份快照

道路、建筑和线路来自导出时的城市状态。游戏里新增一条线路或修改一个站名后，重新导出数据，查看器才会读到这次变化。

建议把城市数据和成品图片分开存放。例如，保留一份“城市名-日期.cmm.gz”，旁边另建文件夹保存不同主题的图片。

## 预览与成品

中央预览便于查看和调整；导出窗口决定最终范围、尺寸和文件位置。导出前看一眼范围参考，确认整城或局部的选择符合预期。

地图缩放和图片尺寸都会影响文字、图标的密度。预览适合确认内容，正式结果适合检查最终排版。
