# CSLModernMap 使用指南

CSLModernMap 把《城市：天际线》和《城市：天际线 II》中的城市数据绘制成地图。你可以查看城市、调整主题和图层，再导出图片、网页地图或线路项目。

游戏内模组负责导出城市数据，电脑上的查看器负责浏览、调整和出图。城市有了变化后，再从游戏导出一份数据即可更新地图。

## 入门

第一次使用，建议按下面的顺序阅读：

1. [开始使用](Quick-Start.md)：安装、导出数据、做出第一张地图。
2. [认识界面与文件](Workspace-and-Files.md)：查看器、城市数据和导出结果各是什么。
3. [主题、图层与文字](Themes-and-Layers.md)：调整地图的内容和外观。
4. [选择范围与导出](Export.md)：全城、局部、PNG 和网页地图。

按需要继续阅读：

- [公共交通图](Public-Transit.md)：查看线路、站点与真实走向。
- [地铁示意图与线路项目](Transit-Diagrams.md)：生成线网、调整排版、保存项目。
- [随机特写与立交合集](Close-Ups.md)：选择城市片段，整理立交图片。
- [常见问题](FAQ.md)：名称、图标、预览和导出问题。
- [English guide](Getting-Started.md)。
