# 主题、图层与文字

[返回目录](Home.md) · [English](Getting-Started.md)

## 主题：一整套地图外观

主题决定背景、水域、道路、建筑、文字等内容的配色与画法。在“样式”的地图主题中选择后，先看整体效果，再决定要调整哪些细节。

想要保存自己的配色，可以进入“编辑主题”，修改后按窗口提供的保存操作保留。日常出图通常只需要选择一个现成主题，再调整少量图层。

## 图层：地图里显示什么

图层像一叠透明纸，每层负责一类内容。

| 图层 | 主要内容 | 常见用途 |
| --- | --- | --- |
| 地形、水域 | 山地、陆地、河流与海岸 | 交代自然环境 |
| 道路、铁路 | 道路、立交和轨道 | 展示城市骨架 |
| 建筑、建成区 | 单栋建筑和连续的城市背景 | 观察开发范围 |
| 兴趣点 | 设施与地点的图标 | 识别学校、医院、站点等位置 |
| 标签 | 道路名、行政区名等文字 | 帮助读图 |
| 行政区划、功能区划、区域上色 | 城市中的区域与范围 | 表达城市分区 |
| 路况 | 导出时记录的交通状态 | 查看道路拥堵分布 |

某些图层依赖游戏版本和数据内容。兴趣点中的设施功能区选择会在 CS2 数据下显示；路况也需要数据中带有对应记录。

## 兴趣点、图标和名称

“兴趣点”就是地图上值得标出的地点。建筑本身、地点图标和地点名称是不同的显示内容，可以分别调整。

遇到地图过密，建议按顺序处理：

1. 降低图标密度，或只显示需要的类别。
2. 缩小图标与文字尺寸。
3. 为想展示的区域单独导出一张局部地图。

地点名称可能来自自定义名称或游戏名称。需要显示更多自动命名的地点时，查看文字与图标设置中的游戏名称选项。

## 建筑颜色与区域颜色

建筑上色表达建筑的分类或当前样式；行政区与功能区颜色表达区域覆盖范围。它们是不同的图层。查看时先确定自己想调整的是一栋建筑，还是整片区域。

## 什么时候使用图标映射

图标映射用于调整某类建筑对应的地点图标。只有遇到分类或图标与预期不一致时，再进入“图标映射”处理；普通出图可以先用默认设置。
