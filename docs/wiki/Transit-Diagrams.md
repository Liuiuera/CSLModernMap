# 地铁示意图与线路项目

[返回目录](Home.md) · [English](Getting-Started.md)

## 示意图与地理地图

地理地图强调位置和实际走向；示意图会整理线路和站点位置，让站序与换乘关系更容易阅读。图上两站之间的距离是排版结果。

CMM 的地铁示意图工作区内嵌了 Rail Map Painter（RMP），可以在生成的线网上继续调整。

## 从城市生成一张线网

1. 打开带有交通线路的城市数据。
2. 选择“地铁示意图”，进入线网工作区。
3. 根据需要选择交通类型、线路与示意图选项，使用生成入口生成草稿。
4. 查看站名、换乘位置和线路布局。
5. 在编辑区调整站点、站名和线路，使版面更合适。
6. 先保存 RMP 项目，再导出 PNG 或 SVG。

重新生成会重新计算草稿。手工调整后，建议先保存当前项目，再尝试另一组生成设置。

## 图片与项目各保留什么

| 保存方式 | 保留的内容 | 后续用途 |
| --- | --- | --- |
| PNG | 固定尺寸的图片 | 分享和常规排版 |
| SVG | 可缩放的矢量图片 | 印刷或在矢量软件中继续排版 |
| RMP 项目 | 当前可编辑的线网 | 在内嵌编辑器或 RMP 中继续编辑 |
| RMG 项目 | 用于 RMG 的线路项目 | 在 Rail Map Generator 中调整线路图 |

RMP 项目在示意图工作区通过“保存”或“另存为”保留。以后使用“打开”读取项目，可以继续编辑。

RMG 项目通过“创建与工具”的 RMG 项目入口生成。它与当前 RMP 画布是两条不同的输出路径；需要保留手工调整后的整张线网时，保存 RMP 项目。

## 让版面更容易阅读

- 先整理拥挤的换乘站，再调整其余站点。
- 给较长的站名留出空间。
- 线路过多时，先做一张重点线路图，再考虑全网版本。
- 保留一份项目文件，方便日后修改站名或版面。
