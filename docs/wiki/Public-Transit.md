# 公共交通图

[返回目录](Home.md) · [English](Getting-Started.md)

## 它表示什么

公共交通图把线路、站点和城市底图放在一起，便于查看交通网络在城市里的位置。线路尽量沿导出数据中的实际走向绘制。

它适合回答“这条线经过哪里”“哪个片区有站点”。如果主要想展示清楚的站序和换乘关系，可以使用[地铁示意图](Transit-Diagrams.md)。

## 基本操作

1. 打开一份带公共交通线路的城市数据。
2. 在“开始”的快速创建，或“创建与工具”的公共交通入口，进入“公共交通图”。
3. 打开“选择线路”，按交通类型和线路选择要显示的内容。
4. 查看站点、站名、线路颜色，以及底图的显示效果。
5. 选择“导出”，保存 PNG。

## 先选线路，再调整样式

线路多时，先只保留要介绍的线路或交通类型。这样更容易检查走向、站点和换乘位置。

随后再调整线宽、站点大小、站名、合并与聚合等设置。合并与聚合会把相近的显示内容集中处理，有助于减少拥挤；密集枢纽可单独放大查看。

## 底图需要多少信息

展示线路覆盖时，可以保留道路、水域与行政区作为参照。若建筑和地点图标让地图显得拥挤，适当减少这些内容，让线路更容易辨认。

导出窗口沿用主窗口中选择的图层和线路。准备导出另一组线路时，先回主窗口修改选择，再检查导出内容。

## 缺少线路时

先确认游戏里已经建成并启用了相应线路，再重新导出城市数据。打开线路列表，检查对应类型和线路是否被选中。可用的交通类型取决于这份城市数据。
