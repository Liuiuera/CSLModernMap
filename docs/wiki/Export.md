# 选择范围与导出

[返回目录](Home.md) · [English](Getting-Started.md)

## 先确定你要的结果

| 结果 | 适合的用途 | 入口 |
| --- | --- | --- |
| PNG 图片 | 分享、打印、后期排版 | 普通地图或公共交通图的“导出” |
| HTML 网页地图 | 在浏览器中拖动、缩放和查看 | 普通地图中的“导出网页” |
| PNG、SVG 示意图 | 使用当前编辑中的线路图版面 | 地铁示意图中的“导出” |
| RMP 项目 | 保存线网，日后继续编辑 | 地铁示意图中的“保存”或“另存为” |
| RMG 项目 | 在 Rail Map Generator 中继续处理线路 | “创建与工具”中的 RMG 项目入口 |

项目文件的使用方式见[地铁示意图与线路项目](Transit-Diagrams.md)。

## 全城与局部

普通地图可以导出全城，也可以选择局部。范围窗口提供完整城市范围、按地块选择和手动绘制范围等方式。

需要导出一个街区时：

1. 在中央预览中找到目标位置。
2. 使用框选，拖出需要的范围。
3. 选择“渲染选区”。
4. 在导出窗口确认范围参考、文件夹与图片尺寸。
5. 执行导出。

框选决定地图包含哪一片区域；图片尺寸决定这一片区域会画得多细。把范围缩小、尺寸保持不变，通常能得到更清晰的局部细节。

## 图片尺寸与质量

图片尺寸按像素填写。2K 或 4K 适合先检查内容，更大的尺寸适合需要细节的成品。

抗锯齿会让道路与文字边缘更平滑，也会增加生成时间和内存用量。可以先用普通质量确认构图，再生成最终图片。

地图旋转用于调整成品朝向。预览里看到的取景、导出窗口选择的范围和最终图片尺寸应一起确认。

## 网页地图

选择“导出网页”，保存 HTML 文件。文件内包含地图数据和浏览所需资源，可以用浏览器打开并分享给别人。

网页地图适合让读者自己缩放查看；PNG 则适合固定版式。两种形式可以从同一份城市数据分别生成。

## 导出完成后

使用“查看结果”或“打开输出文件夹”检查本次输出。PNG 还可以通过“复制本次 PNG”放到剪贴板，再粘贴到聊天或排版软件中。
