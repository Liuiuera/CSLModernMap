# 开始使用

[返回目录](Home.md) · [English](Getting-Started.md)

## 先准备两部分

| 部分 | 用途 | 在哪里使用 |
| --- | --- | --- |
| 游戏内 CSLModernMap 模组 | 读取当前城市，导出地图数据 | 游戏里 |
| CSLModernMap 查看器 | 浏览数据、调整样式、生成地图 | Windows 桌面 |

下载入口：[CS1 创意工坊](https://steamcommunity.com/sharedfiles/filedetails/?id=3781187198) · [CS2 Paradox Mods](https://mods.paradoxplaza.com/mods/159550/Windows)。

游戏内模组需要与游戏版本对应。CS1 和 CS2 使用各自的模组，导出的数据都交给查看器打开。

当前源码中的 Windows 查看器面向 Windows 10 19041 及以上版本、x64 电脑。下载时查看发行说明中的系统和平台信息；使用打包版时，解压后保留完整程序文件夹。

当前仓库入口：[CSLModernMap](https://github.com/Liuiuera/CSLModernMap)。可用下载以模组页面和发行页的实际附件为准。

## 从游戏导出城市

1. 安装并启用对应游戏的 CSLModernMap 模组。
2. 载入想要绘制的城市。Windows 下可在模组设置中使用“安装 / 更新渲染器”准备查看器。
3. 打开模组设置，执行导出城市数据；有“导出并打开”选项时，也可以直接使用。
4. 留意导出完成后的文件位置。

通常会得到 `.cmm` 或 `.cmm.gz` 文件。它是一份用于制图的城市快照。压缩文件可以直接交给查看器打开。

## 做出第一张地图

1. 启动查看器，在“开始”中选择“打开城市”。
2. 选择刚导出的城市数据，等待预览完成。
3. 在“样式”中选择一个地图主题，先保留默认图层。
4. 在“开始”中选择“导出”。
5. 选择 PNG、全城范围和保存文件夹。第一次可以使用 2K 或 4K，便于先确认结果。
6. 导出完成后查看图片，或打开输出文件夹。

确认地图内容合适后，再提高尺寸或微调文字、图标。这样更容易看清每次调整带来的变化。

## 城市更新后

在游戏里重新导出数据，再打开新文件。给文件名加上城市名和日期，有助于保留不同时期的地图。

下一步：[认识界面与文件](Workspace-and-Files.md)。
