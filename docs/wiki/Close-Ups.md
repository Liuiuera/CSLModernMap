# 随机特写与立交合集

[返回目录](Home.md) · [English](Getting-Started.md)

## 随机特写：先帮你选一个位置

随机特写用于从城市里挑一片值得看的区域。你可以按建筑、水边、绿地公园、道路、公共交通等取景偏好尝试不同位置。

1. 打开城市数据。
2. 在“开始”或“创建与工具”中选择“随机特写”。
3. 按需要调整取景偏好和随机种子，再随机选取。
4. 在中央预览中查看结果，必要时继续框选调整。
5. 使用导出入口保存这片区域。

随机选取先改变取景范围，接着由你决定是否导出。相同数据和相同种子便于再次找到同一次取景。

## 立交合集：把多座立交放在一起

立交合集会识别城市里的立交，并把选出的立交整理成拼图。

1. 在“创建与工具”中选择“立交合集”。
2. 设置立交数量和每格尺寸。
3. 选择需要的内容和图层，例如道路、建筑、水域、地点名称和文字标签。
4. 点击“导出立交合集”，选择保存位置。
5. 查看拼图结果，按需要调整数量、尺寸或图层后再次导出。

数量影响拼图包含多少座立交，每格尺寸影响各座立交的细节。想突出道路结构时，可以减少地点图标和文字；想展示城市环境时，可以保留周边建筑与水域。

## 怎么选

| 你想做的事 | 合适的入口 |
| --- | --- |
| 在全城中找一处有意思的景观 | 随机特写 |
| 已经知道要导出哪个街区 | 普通地图框选 |
| 展示多座立交的结构 | 立交合集 |
