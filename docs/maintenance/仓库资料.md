# 仓库资料

以下内容用于审阅后填写 GitHub 仓库设置。JSON 是对应的填写清单。

## 简介与主页

简介：

> City map viewer and renderer for Cities: Skylines and Cities: Skylines II. PNG, HTML and transit diagrams.

中文含义：用于《城市：天际线》和《城市：天际线 II》的城市地图查看器与渲染器，支持图片、网页地图和交通示意图。

Wiki 导入完成后，主页填写 `https://github.com/Liuiuera/CSLModernMap/wiki`。

对应文件：`.github/repository-settings.json`。应用时，将 `topics` 单独填到 Topics，其余字段用于仓库设置。

## Topics

`cities-skylines`、`cities-skylines-2`、`city-map`、`map-rendering`、`transit-map`、`winui3`、`python`、`typescript`、`maplibre`、`game-mod`。

这些词描述游戏、用途和主要实现，方便按主题查找项目。

## 问题标签

对应文件：`.github/labels.json`。按名称补充或更新下面八个标签，保留其他已有标签。

| 标签 | 用途 |
| --- | --- |
| bug | 功能异常或错误 |
| enhancement | 功能建议与改进 |
| documentation | 使用说明与文档 |
| question | 使用问题 |
| cs1 | CS1 相关 |
| cs2 | CS2 相关 |
| renderer | 查看器、地图与线路图 |
| packaging | 构建、安装与发行包 |

一条问题可以同时使用类型和游戏标签，例如 `bug` + `cs2` + `renderer`。

## 版本标签

发行标签采用 `v版本号`，与根目录 `version.json` 对应。当前源码为 `6.7.2f`，首次源码发行草稿使用 `v6.7.2f`。

Topics、问题标签和版本标签各有用途，分别填写。
