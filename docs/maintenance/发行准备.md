# 发行准备

当前源码版本取自根目录 `version.json`，为 6.7.2f。新源码仓库的首份发行记录可围绕本次源码公开编写；Windows 成品包在打包与桌面验收后附加。

## 仓库与文件对应关系

| 位置 | 内容 |
| --- | --- |
| `Liuiuera/CSLModernMap` | 当前渲染器源码、文档与 CI |
| `Liuiuera/CSLModernMap-CodeMod` | CS2 游戏内模组源码 |
| `Liuiuera/CSLModernMap-releases` | 既有 macOS 下载记录 |

旧下载仓库中的 `v6.7.1` 附件为 `macos-x86_64.dmg`。它应继续按原平台说明提供。本仓库的 Windows 包使用清楚的平台文件名。

## 准备 Windows 验收包

1. 在准备发行的提交上运行 CI。
2. 手动运行 `Windows package` 工作流。
3. 下载工作流生成的完整 ZIP、摘要、自检与测试记录。
4. 解压到单独目录，完成下列桌面验收。
5. 确认文件对应的提交、版本与说明后，将已验收 ZIP 和 `SHA256SUMS.txt` 附到发行草稿。

工作流会执行源码测试、Nuitka 构建、引擎自检、WinUI 组装与最终目录自检。打包脚本检查必要程序、翻译与许可文件，保留完整程序目录。

## 桌面验收记录

每项记录使用的系统、数据文件、结果及问题。验收数据覆盖 CS1、CS2 各至少一份真实导出，以及能触发相关功能的城市。

- [ ] 在目标 Windows 系统上解压并启动，确认主窗口、预览与中文路径。
- [ ] 从 CS1、CS2 分别导出城市，测试“导出并打开”和单独打开文件。
- [ ] 切换界面语言，检查功能区、对话框和报错文字。
- [ ] 调整主题、图层、名称与图标，导出全城和局部 PNG。
- [ ] 在复杂立交处检查桥面、道路层次与遮挡；检查有地形和水域的城市。
- [ ] 导出 HTML，在浏览器中打开并断开网络检查浏览。
- [ ] 选择公共交通线路，导出交通 PNG，检查站点与线路。
- [ ] 生成地铁示意图，移动站点和文字，保存并重新打开 RMP；导出 PNG、SVG 和 RMG。
- [ ] 生成随机特写与立交合集。
- [ ] 取消耗时任务、连续打开城市、关闭程序，检查进程是否正常结束。
- [ ] 在较大城市和较高图片尺寸下完成一次导出，记录耗时和异常。
- [ ] 检查最终包中的程序、资源与第三方许可，确认摘要对应上传附件。

## 填写发行草稿

版本从 `version.json` 读取，标签使用 `v版本号`。发行说明写清楚本次记录的内容、平台、开始方法和反馈入口。具体更新项以实际提交和验收结果为依据。

源码发行可以先使用 GitHub 自动生成的源码归档。Windows 下载附件在桌面验收后加入同一草稿；需要试用反馈时，再按实际状态设置预发行。

## 发布后核对

检查发行页的版本、附件平台、校验摘要和文档入口，再通过常用模组入口确认用户能找到相应说明。
