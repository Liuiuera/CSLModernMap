# 构建 Windows 渲染器

渲染器由 WinUI 界面和 Python 引擎组成，面向 x64 Windows 10 19041 或更高版本。

以下命令均在仓库根目录执行。

## 环境准备

安装 Python 3.13、Node.js 24 和 .NET SDK 10，然后安装 Python 依赖：

```powershell
python -m pip install -r dev/CSLModernMapRenderer/requirements-build.txt
python -m pip install nuitka ordered-set zstandard
```

首次构建需要联网下载 npm 和 NuGet 依赖。

## 生成渲染器 exe

先编译 Python 引擎，再构建 WinUI 界面并组合两个组件：

```powershell
python dev/CSLModernMapRenderer/build_nuitka.py --mode standalone
python dev/CSLModernMapRenderer/winui/assemble.py --publish
```

WinUI 构建会自动准备 MapLibre 网页预览和内嵌 RMP 编辑器，并从锁文件安装前端依赖。已有资源且源码未变化时跳过对应步骤。

生成完成后，运行：

```text
dev/CSLModernMapRenderer/dist/winui/CSLModernMapRenderer/CSLModernMapRenderer.exe
```

`engine/` 子目录包含编译后的 Python 引擎，`Assets/` 和其他依赖文件也供程序运行使用。运行时保留这些文件及目录，不能只取出顶层 exe。

## 生成小于 80 MB 的下载包

安装 7-Zip 后，在完成上述引擎编译和装配的基础上执行：

```powershell
python tools/renderer/package_release.py --seven-zip "C:\Program Files\7-Zip\7z.exe"
```

输出在 `dev/CSLModernMapRenderer/dist/releases/`，包含 `.7z` 和 SHA-256 校验文件。脚本使用 LZMA2 固实压缩，校验归档完整性；最终归档达到 80,000,000 字节时构建失败。这里的门槛是下载大小，不是解压后的磁盘占用。用户需用支持 7z 的工具解压整个目录。WebView2 继续使用系统共享的 Evergreen Runtime，不包含在包中。

Release 发布采用 .NET 部分裁剪，显式保留应用、Ribbon、WinUI 和 WinRT 投影程序集，并保留 JSON 反射序列化。Python 引擎排除第三方测试辅助模块、F2PY 编译工具和运行时不使用的文档字符串。地图几何、图像格式、语言和字体支持继续保留。

升级 .NET、Windows App SDK、RibbonSpace 或 Python 依赖后，需要重新核对裁剪警告，并验证启动通信、语言资源、预览、导出和 RMP。保留程序集并不能替代运行检查，不应全局屏蔽裁剪警告。仅将文件压缩成单个 exe 也不能替代这些验证。

## 从源码运行界面

如果只需调试界面，可以直接构建 WinUI 项目：

```powershell
dotnet build dev/CSLModernMapRenderer/winui/CSLModernMapWinUI.csproj -c Release
```

默认输出目录为：

```text
dev/CSLModernMapRenderer/winui/bin/Release/net10.0-windows10.0.19041.0/win-x64/
```

运行其中的 `CSLModernMapRenderer.exe`。此方式使用源码中的 Python 引擎，需要保留仓库目录结构和已安装的 Python 依赖。

## 常见构建问题

- 找不到 Python、npm 或 dotnet：确认对应工具已加入 `PATH`，并重新打开终端。
- 缺少网页预览资源：运行 `python tools/renderer/build_preview_viewer.py`。
- 缺少内嵌编辑器资源：运行 `python tools/renderer/build_rmp_editor.py`。
- 提示引擎目录不完整：确认 Nuitka 构建成功，再运行 WinUI 组合命令。
