# Rail Map Painter icons

These SVG assets are sourced from the GPL-3.0 licensed `railmapgen/rmp`
repository: <https://github.com/railmapgen/rmp>.

- Facility SVGs: `public/images/facilities/`
- Chongqing station geometry: `src/components/svgs/stations/`

The renderer rasterizes these SVGs at high resolution before compositing them
into the PNG output.
